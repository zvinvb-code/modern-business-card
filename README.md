# Business Card Website

A responsive digital business card developed using **HTML5 and CSS3**. The project features a modern glassmorphism design, gradient effects, hover animations, and a clean professional layout.

## Technologies

* HTML5
* CSS3

## Features

* Responsive design
* Modern UI
* Glassmorphism effects
* CSS hover animations
* No JavaScript or external libraries

## Project Structure

```text
business-card/
├── index.html
├── style.css
└── README.md
```

## Usage

Open `index.html` in any modern web browser to view the business card.
